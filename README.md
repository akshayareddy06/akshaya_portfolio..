# V Sai Akshaya — Portfolio Website

A responsive personal portfolio built with HTML, CSS and vanilla JavaScript.

## Preview locally

1. Extract the ZIP file.
2. Open the `akshaya-portfolio` folder.
3. Double-click `index.html` to open it in your browser.

For the best development experience, open the folder in VS Code and use the Live Server extension.

## Publish using GitHub Pages

1. Sign in to GitHub.
2. Create a new **public** repository named exactly `akshayareddy06.github.io`.
3. Open the repository and choose **Add file → Upload files**.
4. Open the extracted `akshaya-portfolio` folder on your computer.
5. Upload the contents inside that folder (`index.html`, `css`, `js`, `assets`, and `README.md`). Do not upload the ZIP itself and do not put the files inside another nested folder.
6. Commit the upload to the `main` branch.
7. Go to **Settings → Pages**.
8. Under Build and deployment, select **Deploy from a branch**.
9. Choose branch `main` and folder `/ (root)`, then Save.
10. Wait a few minutes. Your site should appear at:

   https://akshayareddy06.github.io/

## Before publishing

- Check that the GitHub repository links are correct.
- Add your email address if you want it displayed publicly.
- Add your resume PDF inside `assets/resume/` if you want a downloadable resume link. The current design intentionally does not show a non-working resume button.
- The contact section links to LinkedIn and GitHub; it does not contain a fake contact form.

## Edit your details

- Main page content: `index.html`
- Colours, typography and layout: `css/style.css`
- Navigation and scroll effects: `js/script.js`

## Notes

This is a static website. It does not need a server, database, API key or paid hosting. Google Fonts are loaded from the internet; the site will use fallback fonts if they are unavailable.
